# OpenClaw 工作助理使用说明

本文档说明当前 `openclaw-skills` 中工作助理能力如何使。

## 1. 主动触发功能

主动触发功能由用户当场发起。OpenClaw 只有收到用户输入、触摸入口或用户二次确认后才执行。

### 1.1 飞书日程创建

用户示例：

```text
明天上午10点到11点的项目会，帮我建一个飞书日程，邀请张三、李四参会。
```

OpenClaw 行为：

- 解析标题、日期、开始时间、结束时间。
- 解析参会人并查询飞书通讯录。
- 创建飞书日程并邀请参会人。
- 时间、标题、参会人缺失或有歧义时先追问，不直接创建。

预期回复：创建成功时返回适合语音播报的 `speech`，并在 `actions` 中记录 `lark.calendar.create` 等动作。

### 1.2 触摸或询问今日日程播报入口

对应需求：日程播报的触摸入口。

触发入口：

- 用户触摸、主动提问。
- 这是用户主动触发的日程播报入口，不等同于每天定时播报。
- 推荐将机器人端事件明确标注为“日程播报意图”，再转换为 `daily_briefing_triggered`。

说明：

- 若机器人端已明确把摸头映射为“播报今日安排”，则复用 `agenda_briefing` 能力。
- 该能力是只读能力，不创建或修改飞书日程。

### 1.3 会议迟到通知

对应需求：会议迟到通知。

触发入口：

- 通常先由被动的 `meeting_starting_soon` 会前提醒建立 `context.current_focus`。
- 用户随后主动说“我会晚到五分钟，帮我通知参会人”。
- 推荐事件类型：`user_utterance`。
- 推荐结构化意图：`payload.structured_intent.type = "meeting.notify_late"`。

用户示例：

```text
我这里还有个电话会议没结束，帮我跟参会人员说一下，晚五分钟到。
```

OpenClaw 行为：

- 从 `context.current_focus` 识别刚刚提醒的会议。
- 找到会议群或参会人通知目标。
- 通过飞书发送迟到通知。
- 没有会议上下文或通知目标时先追问，不发送消息。

### 1.4 久坐提醒后的轻量陪伴

对应需求：久坐关怀后的段子、放松建议或轻量聊天。

触发入口：

- 先由被动的 `sedentary_detected` 触发久坐提醒。
- 用户接受后再主动触发二次陪伴。
- 推荐事件类型：`wellbeing_companion_requested`。

用户示例：

```text
好，讲个轻松点的。
```

## 2. 被动触发功能

被动触发功能不依赖用户当场发起。它们需要调度器、机器人感知服务或外部事件先产生结构化事件，再交给 OpenClaw 处理。

### 2.1 定时日程管理及播报

对应需求：早上 9:30 定时日程管理及播报。

触发入口：

- 为了拍摄最好在服务器手动触发，目前设置的每日早上 9 点自动播报。
- 触发条件：到达配置的工作日日程播报时间。

OpenClaw 行为：

- 查询今日日程。
- 查询上周或近期工作日日程。
- 统计内部会议、客户接待、外出活动、深度工作等分类。
- 生成工作复盘和今日日程重点提醒。

### 2.2 会议会前提醒

对应需求：早上 11:00 会议会前提醒。

触发入口：

- 用户在当前日程中设置一个日程，在日程开启前 2 分钟会自动触发（日程名称包含关键词 会议）。
- 触发条件：检测到会议还有 2 分钟开始，N 由 `offsetMinutes` 配置。

OpenClaw 行为：

- 读取会议标题、开始时间、地点、会议室、参会人或通知目标。
- 生成会前提醒。

### 2.3 日常外勤出行规划

对应需求：下午 14:40 日常外勤出行规划。

触发入口：

- 用户在当日日程中设置一个日程（包含 外勤、客户拜访 关键词）。
- 触发条件：检测到用户当日有外勤、客户拜访、园区拜访等日程，并到达提前提醒时间。

OpenClaw 行为：

- 从日程标题、地点、备注中提取目的地，默认不计算规划路线。
- 路线不可用时降级为提醒用户预留充足时间，不编造路线。

### 2.4 久坐关怀

对应需求：下午 15:00 久坐关怀情绪陪伴。

触发入口：

- 机器人端或感知服务触发。
- 触发条件：感知服务判断用户连续久坐，并提供时长和置信度。

OpenClaw 行为边界：

- 不负责每隔 20 分钟拍照识别。
- 不负责相机采集、姿态识别、机器人运动或灯光控制。
- 负责接收结构化久坐事件，判断是否适合打扰用户。
- 避开会议中、通话中、刚提醒过等不适合打扰的场景。
- 可以结合近期日程顺带提醒即将发生的事项。

### 2.5 异地出差出行建议

对应需求：下午 18:30 异地出差出行建议。

触发入口：

- 需要在日程中设置第二天的出差日程（最好包含 出差 这个关键词），在到达当天提醒时间后会自动触发（18:00）。
- 触发条件：检测到第二天有出差、差旅、航班、高铁、酒店等相关日程，并到达前一日提醒时间。

OpenClaw 行为：

- 从日程标题、地点、备注中提取目的地城市。
- 查询目的地天气。
- 根据天气、温差、备注生成携带和着装建议。
- 天气不可用时降级为出差事项提醒，不编造天气。
